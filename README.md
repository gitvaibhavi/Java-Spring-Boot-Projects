# Java & Spring Boot Projects

A collection of Java and Spring Boot applications developed to explore backend development, database integration, REST APIs, CRUD operations, and web application development.

## Projects

### Spring CRUD Application

A RESTful employee management application built with Spring Boot, Spring Data JPA, Hibernate, and MySQL.

**Features**
- Create employee records
- Retrieve employee records
- Retrieve an employee by ID
- Update employee information
- Delete employee records
- REST API integration
- MySQL database integration

**Technologies**
- Java 17
- Spring Boot 3.2.5
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Postman

[View Project →](./Spring-CRUD-Application)

### Spring Boot Web Application

A web-based employee management application built with Spring Boot, Spring Data JPA, Hibernate, MySQL, and Thymeleaf.

**Features**
- Add employee records
- Display employee records
- Store employee information in MySQL
- Thymeleaf web interface
- Spring Data JPA integration

**Technologies**
- Java 17
- Spring Boot 3.2.5
- Spring Data JPA
- Hibernate
- MySQL
- Thymeleaf
- Maven
